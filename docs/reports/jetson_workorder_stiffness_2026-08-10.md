# 작업지시 — stiffness 와 kt 를 한 번에 가르는 정적 부하 시험 (2026-08-10)

대상: 잿슨 `parksuho@192.168.137.7`. 로봇은 **매달아 놓고** 한다.
소요: 30 분 내외. 필요한 것 — **질량을 아는 추 하나**(0.5~1 kg 권장, 저울로 잰 값),
줄, 자.

---

> **정정 (2026-08-10, 초판 직후).** 초판은 후보를 "37.65 vs 75" 로 적었다. **틀렸다.**
> `stiffness = 75 × (kt/R)` 라 **kt 단독이 아니라 kt/R 비율**에만 의존한다. kt 가
> 2 배여도 R 이 함께 커지면 stiffness 는 안 변한다. 제대로 풀면 방향이 반대다 —
> ROBOTIS 규격 쪽이 **더 무른** 26.1 을 가리킨다. 아래 표를 고쳤다.
> **시험 절차 자체는 그대로 유효하다** (측정값이 k 를 직접 준다).

## 왜 하는가 — 두 값이 서로 안 맞는다

심의 액추에이터 게인은 BAM 실측 `m4.json` 에서 유도했다:

```
stiffness = (1/128) × kp_register(800) × vin(12.0) × kt/R = 37.65 N·m/rad
damping   = kt²/R + friction_viscous = 0.505 + 0.847 = 1.352
   (kt = 1.0057 N·m/A,  R = 2.0033 Ω)
```

`stiffness` 를 정하는 건 **kt/R** 하나다. 그 값을 두 경로로 구하면 안 맞는다.

| | kt/R | stiffness | 함의 스톨토크 | 함의 무부하속도 |
|---|---|---|---|---|
| BAM `m4.json` | 0.502 | **37.65** | 6.02 N·m | 4.40 rad/s |
| ROBOTIS 규격 | 0.348 | **26.10** | 4.10 N·m | 4.82 rad/s |

(ROBOTIS 쪽: `kt/R = (τ_stall + friction_base)/V = (4.1 + 0.076)/12 = 0.348`)

**두 세트 다 자기일관적이다** — 각자의 스톨과 무부하 속도가 서로 맞아떨어진다.
차이는 BAM 이 스톨 토크를 **47 % 더 세게** 본다는 것이고, 그렇다면 심의 다리가
지금 실기보다 **세게** 밀고 있다는 뜻이다 (무르게가 아니다).

### 스텝응답으로는 못 가른다 (이미 확인했다)

시도할 만해 보이지만 안 된다. kt 가 2 배가 되면 stiffness 는 2 배(kt/R)인데
**damping 은 4 배**(kt²/R)라, 지배 극점 k/c 가 27.8 → 26.3 으로 **5 % 밖에
안 변한다.** 수치적분 결과:

| stiffness | damping | 2° 계단 상승시간 | 5° | 20° |
|---|---|---|---|---|
| 37.65 | 1.352 | 72.5 ms | 62.5 ms | 71.4 ms |
| 75.31 | 2.866 | 82.6 ms | 76.3 ms | 82.7 ms |

차이 10~14 ms 이고 **부호도 반대다**(강성이 큰 쪽이 오히려 느리다). 기존
`joint_step_test.py` 는 `time.sleep(0.05)` = 20 Hz 라 한 샘플도 안 되고,
50 Hz 로 올려도 측정 지터가 3 ms 라 못 잡는다. 주파수응답도 대역폭
4.9 vs 4.6 Hz 로 같다. **동특성은 거의 불변이다.**

### 전류로 토크를 재는 것도 안 된다 — 순환논법

`k = τ / 오차` 에서 τ 를 전류로 구하면 τ = kt·I 인데, kt 가 바로 다투는 값이다.
kt 가 2 배면 τ 도 2 배, k 도 2 배로 **같이 움직여서 아무것도 안 갈린다.**

### 그래서 — 물리적으로 알려진 부하

질량과 팔 길이로 토크를 정하면 kt 가 안 끼어든다.

```
k = m·g·L / 정착오차          ← kt 없음. 이것만이 가른다.
kt_eff = m·g·L / ΔI           ← 덤. 1.95 배 문제도 같이 풀린다.
```

## 절차

### 준비

1. 로봇을 **매달아 놓는다**(발이 바닥에 안 닿게).
2. 시험 관절은 **`left_knee`** 를 쓴다 (팔 길이가 길어 토크가 크고, 이번
   보행에서 문제를 일으킨 축이라 겸사겸사 본다).
3. 무릎을 굽혀 **정강이(무릎축→발목축)가 수평**이 되게 둔다. 수평이어야
   τ = m·g·L 이 그대로 성립한다 (기울면 cos 을 곱해야 하고 각도 오차가 그대로
   토크 오차가 된다).
4. **L 을 자로 잰다** — 무릎 회전축에서 추를 매다는 지점까지의 수평 거리 (m).
5. **m 을 저울로 잰다** (kg). 추 + 줄 + 고리 전부 포함.
6. 전류 상한은 `--current 700` (rl_walk 와 같게).

### 측정

각 조건에서 **정착 후** (지령을 준 뒤 2 초 이상 대기, 관절속도 ≈ 0) 위치와
전류를 50 샘플 이상 기록해 평균낸다.

| # | 조건 | 기록 |
|---|---|---|
| A | 추 없음, 지령 θ₀ (정강이 수평) | 위치 θ_A, 전류 I_A |
| B | **추 매달고**, 같은 지령 θ₀ | 위치 θ_B, 전류 I_B |
| C | 추 유지, 지령 θ₀ 그대로 — **반대 방향에서 접근** | 위치 θ_C, 전류 I_C |
| D | 추 없음 — **반대 방향에서 접근** | 위치 θ_D, 전류 I_D |

**"반대 방향에서 접근"이 왜 필요한가**: 정지마찰(friction_base 0.076 N·m) 때문에
관절이 목표 주변 ±0.116° 안 아무 데나 멈춘다. 위에서 내려와 멈춘 값과 아래에서
올라와 멈춘 값을 **평균내면 이 히스테리시스가 상쇄된다.** 안 하면 결과에
±10 % 가 실린다.

구체적으로 C·D 는 지령을 θ₀ 보다 10° 낮췄다가 다시 θ₀ 로 올려서 정착시킨다
(A·B 는 10° 높였다가 내려온 것으로 한다 — 둘 중 어느 쪽이든 **반대이기만**
하면 된다).

### 계산

```
θ_추없음 = (θ_A + θ_D) / 2
θ_추있음 = (θ_B + θ_C) / 2
Δ오차   = |θ_추없음 − θ_추있음|          [rad]
Δ토크   = m × 9.81 × L                    [N·m]
ΔI      = |(I_B + I_C)/2 − (I_A + I_D)/2| [A]

stiffness = Δ토크 / Δ오차
kt_eff    = Δ토크 / ΔI
```

**차분을 쓰는 이유**: 다리 자체 무게, 지령 오프셋, 전류 오프셋(무부하 0.27 A)이
전부 빠진다. 절대값을 안 믿어도 되게 만드는 것이다.

## 예상 결과 — 어느 쪽이든 명확히 갈린다

| 추 | 팔길이 | Δ토크 | 천장(3.16)대비 | Δ오차 @37.65 | Δ오차 @26.1 | 두 값 차이 |
|---|---|---|---|---|---|---|
| 0.5 kg | 15 cm | 0.74 N·m | 23 % | 1.12° | 1.62° | 5.6 카운트 |
| **1.0 kg** | **15 cm** | **1.47 N·m** | **47 %** | **2.24°** | **3.23°** | **11.3 카운트** |
| 1.5 kg | 15 cm | 2.21 N·m | 70 % | 3.36° | 4.85° | 16.9 카운트 |
| 1.5 kg | 20 cm | 2.94 N·m | 93 % | 4.48° | 6.46° | 22.5 카운트 |

엔코더가 0.088°/카운트다. **1.0 kg / 15 cm 를 기본으로 하고**, 결과가 애매하면
1.5 kg 로 한 번 더 재서 두 점이 같은 기울기를 주는지 본다 (두 점이면 선형성까지
확인된다 — 한 점만 재면 오프셋과 기울기를 구별 못 한다).

**마지막 줄(93 %)은 피할 것** — 천장에 가까우면 포화가 섞여 `k = τ/오차` 가
깨진다.

### 주의

* **추를 걸었을 때 전류가 상한(700 틱)에 닿으면 안 된다.** 닿으면 포화라
  `k = τ/오차` 가 성립하지 않는다. 1.47 N·m 는 천장 3.16 N·m 의 47 % 라 여유가
  있지만, 로그의 `pwm` 이 100 % 로 붙어 있으면 추를 가볍게 바꿀 것.
* 지령은 **URDF 클램프를 통과한 값**을 기록할 것. `joint_step_test.py` 가
  클램프 **전** 값을 CSV 에 적어서 잔여오차를 18.7° 로 오독한 전례가 있다
  (`hw_v40_followup_2026-08-10.md` §5.4).
* `left_knee` 는 보행 중 간헐 정지(전류 0.003 A 로 240 ms) 가 관찰된 축이다.
  이번 시험에서 전류가 갑자기 0 으로 떨어지는 구간이 나오면 **그 구간을 빼고**
  계산하고, 나온 사실을 따로 보고할 것. 그 자체가 §4 미해결 문제의 단서다.
* 온도를 시험 전후로 읽을 것. 추를 건 채 오래 두지 말 것 (한 조건 10 초 이내).

## 이 결과로 무엇이 바뀌나

* **37.65 근처로 나오면**: BAM 이 맞다. 심 게인을 그대로 두고, ROBOTIS 규격과의
  차이는 "이 개체가 규격보다 세다"로 정리한다 (BAM 은 **우리 실물 한 대**를 잰
  것이고 규격은 대표값이다 — 개체차는 있을 수 있다).
* **26 근처로 나오면**: BAM 의 kt/R 이 47 % 높았다는 뜻이고, 심의 다리가 지금까지
  실기보다 **세게** 밀고 있었다. `stiffness 26.1` 로 바꿔 v42 를 학습해야 한다.
  damping 도 함께 다시 정해야 한다 — 규격 자기일관 값은
  `kt²/R + friction_viscous = 0.851` 이다 (지금 1.352).
  이건 v41 의 토크-속도 결합과는 **별개의 두 번째 sim2real 갭**이다.
* **둘 다 아니면**: 측정값이 진실이다. 그 값을 쓰고 두 유도 모두 폐기한다.

어느 쪽이든 v41 학습(진행 중, 봉투는 ROBOTIS 기준)에는 영향이 없다.
이 시험은 v41 과 병렬로 진행해도 된다 — 다만 **GPU 가 아니라 로봇을 쓰므로
학습과 충돌하지 않는다.**
